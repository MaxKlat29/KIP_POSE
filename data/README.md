# data/

Large/binary simulation inputs and outputs. The payload is **not** committed to
git (see the repo `.gitignore`) — only this README and the directory
placeholders are tracked.

| Path | Content | Source |
|------|---------|--------|
| `data/usd/` | USD assets: parts (`Anker_Kurz.usd`, `Anker_Lang.usd`, …) + the scene (tray + Zivid camera) | delivered separately |
| `data/output/` | Rendered datasets (RGB / bbox / segmentation / depth) | generated by `sim_code/run_sdg.py` |

## Conventions

- The SDG pipeline resolves USDs from `SDG_USD_DIR` (default: `data/usd/`).
- Rendered output goes to `SDG_OUTPUT_DIR` (default: `data/output/`).
- On the workstation these typically live under `/mnt/data/kip_pose/data/`.
